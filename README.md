# LITORAL NEA ERP

Aplicación web integral para **LITORAL NEA SRL**, orientada al control de obras,
ingeniería, administración, abastecimiento, finanzas, flota y recursos humanos.

La solución se entrega como monorepo con frontend Next.js/React/TypeScript,
backend NestJS, PostgreSQL, Prisma, Docker y documentación operativa.
